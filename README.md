# english-course-website-
“English course website built with HTML, CSS, JavaScript and Bootstrap.


##  Features

- Responsive design
- Interactive slider
- FAQ accordion
- Instructor cards
- Contact form validation
- Language switch button

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Purpose

This project was created to improve my front-end development skills and build real-world projects as a computer engineering student. A modern website concept for an English course.
